# Haslap

El contexto de este repo vive en [AGENTS.md](AGENTS.md). Léelo antes de tocar nada.

Resumen de los límites que más se rompen por descuido:

1. **La web no muestra estadísticas ni funciones sociales** — eso es de la app. Se enseñan
   bloqueadas con CTA de descarga. → [docs/producto.md](docs/producto.md)
2. **El color sigue la regla 60/25/10/5** — blanco domina, verde es identidad, el texto
   nunca es `#000`, el flúor es acento escaso. → [docs/marca.md](docs/marca.md)
3. **Nada de cifras, testimonios ni logos inventados** en pantalla. → [docs/contenido.md](docs/contenido.md)
4. **Las animaciones nunca bloquean el render** — solo se anima la entrada.
